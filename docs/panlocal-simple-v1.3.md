# PanLocal V1.3 · 个人专用简洁版

## 用户需求
个人专用，希望开发者 App Key / SecretKey 不必每次手动输入，页面不再堆叠大量 OAuth 实验与诊断按钮；暂时无法远程操控新加坡服务器。

## 本轮改动

- APP 首页突出 **“打开我的网盘”**，分享链接、旧版 OAuth Bridge、日志操作保留在“更多功能”中。
- “我的网盘”页面默认只显示 **首次设置 → 授权 → 搜索** 的主流程，不再让用户面对多套实验模式和大量长按钮；旧版兼容、手动 dlink 检查及清除授权隐藏在“高级功能 / 诊断”。
- 从用户此前自己提供的开发者控制台信息预填 **公开的 App Key**（仅 OAuth 的 client_id，若不匹配仍可在本机修改）。**真实 SecretKey 未写入仓库或 APK**。
- 继续使用 Android Keystore AES-256-GCM 加密保存个人 SecretKey；首次输入保存后以后不必重复填写。
- **新增 OAuth Access Token / Refresh Token 的本机加密保存与自动刷新**。如果保存的令牌有效则直接恢复登录；即将过期时调用百度官方令牌刷新接口。百度拒绝、令牌撤销或缺少 refresh_token 时才提示重新获取一次性授权码。
- 授权码仍由百度官方 OOB 流程产生，首次须手动粘贴；“粘贴 code 并登录”可在用户点击后读取手机剪贴板，减少操作。
- 百度 CDN 的首字节下载验证、TXT 导出、分享链接解析等功能继续保留。**完整 2.27GiB 视频下载仍未经验证。**
- 不需要新加坡服务器、SSH 或远程工具额度。不会将用户密码、SecretKey、Access Token/Refresh Token 或带签名 dlink 上传到公开仓库或诊断日志。

## 安全限制

- 公开发行的 APK 无法安全保守硬编码的 SecretKey，即使用户表示不介意泄露也可能造成应用凭据被他人盗用。为达成“以后免输入”，改为 Android Keystore 保存并在授权时读取。
- 已曝光过的 SecretKey 应在百度后台轮换；仅在可信设备输入新密钥。
- 用户清除 APP 数据、卸载或因签名变更重装后会丢失 Keystore 加密存储，必须重新配置；更新前导出 TXT 日志。
- OAuth 令牌过期、百度不提供 refresh_token、授权被撤销或账号权限变化时可能需要再次授权。不能承诺永久免登录。
- 自动续期及搜索、dlink、Range 实际下载需要用户手机实测；Actions 编译通过只证明可构建。

## 建议实测

1. 安装 V1.3，打开“我的网盘”；如果未保存密钥，确认预填 App Key，输入 **轮换后的** SecretKey，点“保存开发者密钥”。
2. 第一次点“打开百度官方授权”，复制官方 code，返回点“粘贴 code 并登录”。
3. 搜索自己视频，核实搜索到的路径和文件大小，取得 dlink 并尝试 APP 内首字节测试。
4. 关闭/重开 APP；确认无需输入密钥或 code 就能恢复授权。测试自动续期需等真正过期，不得凭重新打开就标记“自动续期通过”。
5. “高级功能”里可清除已保存账号授权及密钥。
